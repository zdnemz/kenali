# Coverage manifest — Kenali

> **This is a plan, not a claim of completion.** One row per FR / NFR / SEC id extracted from `docs/prd.md` (50 ids total: FR-01…FR-20, NFR-01…NFR-10, SEC-01…SEC-20). File and test references may point to paths that later waves will create. No hardware, VM, camera, TPM or LogonUI test has been executed on this host; anything requiring Windows runtime is delivered as scripts plus manual steps (see BRIEF.md).
>
> **Status values:** `in progress` = wave-1 foundation work (host-compiled / host-tested here); `host-tested` = a wave-1 unit/property test is expected on this Linux host (`cargo test --locked -p <crate>`); `planned` = wave 2–5 work, Windows runtime, or manual/owner-run proof. Windows crates are type-checked only (`cargo check --target x86_64-pc-windows-msvc --locked`), never linked or run here.
